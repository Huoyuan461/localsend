# 直传 (Zhichuan)

手机、电脑之间互传文件，原画质、不压缩、不花钱。

[![CI](https://github.com/Huoyuan461/localsend/actions/workflows/ci.yml/badge.svg)](https://github.com/Huoyuan461/localsend/actions/workflows/ci.yml)

## 为什么用直传

- **微信传视频被压缩？** 直传走本地直连，原画质、满速传输，1GB 视频几秒钟传完。
- **安卓传 iPhone？** AirDrop 不支持安卓。直传打通安卓 ↔ iPhone ↔ Windows ↔ Mac，全平台互传。
- **没网也能传？** 只要设备连着同一个 Wi-Fi（甚至没有外网），照样传。

## 怎么用

两台设备打开直传 → 选文件 → 点发送 → 对方点接收。就这么简单。

- 不用注册账号，不上传云端，不看广告
- 传输全程加密，文件只在你的设备之间走，不经过任何服务器
- 个人使用完全免费
